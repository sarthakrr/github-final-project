# This is the README.md file for the **github-final-project**

A calculator that calculates simple interest given principal, annual rate of interest and time period in years.

## Input

- `p`: Principal amount
- `t`: Time period in years
- `r`: Annual rate of interest

## Output

Simple interest = `p * t * r / 100`

## Usage

Run the `simple-interest.sh` script and enter the principal amount, time period in years, and annual rate of interest when prompted.

## Example

For a principal of 1000, an annual interest rate of 5%, and a time period of 2 years:

Simple interest = 1000 * 2 * 5 / 100 = 100
